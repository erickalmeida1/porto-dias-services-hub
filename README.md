# Porto Dias Services Hub

Crie uma página única e simples para o Hospital Porto Dias, usando a logo anexada e seguindo sua identidade visual.

Título: Conheça nossos Serviços

Abaixo, exiba uma grade responsiva de cards:

3 colunas no desktop

2 no tablet

1 no mobile

Cada card deve ter:

o mesmo ícone médico para todas as especialidades;

nome da especialidade;

link externo clicável em todo o card, abrindo em nova aba.

Use inicialmente:
Cardiologia, Ortopedia, Neurologia, Pediatria, Ginecologia, Dermatologia, Oftalmologia, Endocrinologia e Gastroenterologia.

Visual clean, institucional e moderno, seguindo as cores da logo do Hospital Porto Dias. Cards brancos, bordas suaves, cantos arredondados e hover discreto.

Organize as especialidades em um array com nome e url para facilitar a troca dos links depois.

Não criar backend, login, formulários, páginas adicionais ou seções extras.
